# Air Quality Dashboard

Proyek ini merupakan analisis data kualitas udara menggunakan Beijing Multi-Site Air Quality Dataset periode Maret 2013 hingga Februari 2017.

Dashboard dibuat menggunakan Streamlit untuk menampilkan hasil analisis konsentrasi PM2.5 berdasarkan stasiun pemantauan dan kategori kecepatan angin.

## Setup Environment

Buka terminal pada folder utama submission, kemudian install seluruh library yang dibutuhkan:

```bash
pip install -r requirements.txt
```

## Run Streamlit App

Masuk ke folder dashboard:

```bash
cd dashboard
```

Jalankan aplikasi Streamlit:

```bash
streamlit run dashboard.py
```
